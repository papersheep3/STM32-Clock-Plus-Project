# STM32-Clock-Plus-Project
第一个裸机MCU项目，基于b站UP主梅花七月香，后续会融合其他功能以及拓展到FreeRTOS系统

此分支用于保存裸机的代码。

# 用到的硬件
STM32F103C8T6 主控芯片

1.54 inch LCD ST7789驱动：用于显示

ESP32-C3 WIFI模块：用于获取天气数据

MCU6050 六轴传感器：用于获取环境温度数据


基于以上硬件可以实现项目中的天气时钟功能：从知心天气中抓取指定地址天气数据，从MPU6050模块获取环境温度，从RTC实时时钟获取时间，将数据显示在LCD显示屏中

# 拓展的功能
基于家用需求，我希望能添加一个红外模块，一个舵机，实现远程按键遥控关灯功能

可以添加一个声控模块

可以添加一个扬声器模块，用于增加趣味性

可以添加一个休眠功能，使得通过舵机遥控关灯后LCD熄屏，使环境保持漆黑更加易于睡觉


目前尚不知道这些功能是否可以裸机实现，代码量导致的内存问题可能出现，任务阻塞问题也可能出现，只是作为一个接下来的设计构想。
